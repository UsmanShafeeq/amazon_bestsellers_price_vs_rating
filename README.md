# 📊 Amazon Bestseller Analysis: Price vs User Ratings (2009–2019)

This project analyzes the **relationship between book prices and user ratings** among Amazon bestsellers over a decade (2009–2019). It focuses on **pricing trends, genre differences, and top authors**, providing actionable insights for publishing and e-commerce analysis.

---

## 🔍 Key Insights
- Most books are priced **under $20**.  
- **User ratings are consistently high** (4.5–5.0), indicating strong customer satisfaction.  
- **Weak correlation** between price and ratings → higher price does **not guarantee higher ratings**.  
- Non-Fiction books tend to have slightly **higher prices** than Fiction.  
- Certain authors (**Stephen King, JJ Smith, Jordan B. Peterson**) appear **frequently on bestseller lists**.

- `amazon-bestsellers-price-vs-rating.ipynb` – Full analysis notebook with EDA, graphs, and insights.
